# PhaserRaft

PhaserRaft is a containerized, real-time data processing engine that enables automated deployment on scalable cloud platforms.

The key benefits of using PhaserRaft include:

- PhaserRaft is a containerized, real-time
- data processing engine that enables
- automated deployment on scalable cloud

## Technology Stack

- javascript

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/PhaserRaft.git`
2. `cd PhaserRaft`
3. Install in editable mode: `pip install -e .`

## Configuration

PhaserRaft is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
